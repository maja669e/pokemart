
# PokéMart

A Pokémon-themed webshop.

## Projects

- `shopping-cart/` — Part 1: React and Redux Toolkit.
- `shopping-cart-next/` — Part 2: Next.js App Router.

## Requirements

- Node.js
- npm

## Run Part 1 — React

```bash
cd shopping-cart
npm install
npm run dev
```

## Run Part 2 — Next.js

```bash
cd shopping-cart-next
npm install
npm run dev
```

The Next.js application runs at http://localhost:3000 by default.


## Technologies

React, Redux Toolkit, Next.js, JavaScript, CSS and PokéAPI.
